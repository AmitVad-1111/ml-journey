Step 1 — Input Sequence
A sentence is broken into tokens (words or subwords). Each token becomes a numeric vector via an embedding lookup. Click any token to set it as the Query — the token asking "what should I attend to?"

Step 2 — Linear Projections: Query, Key, Value
Attention(Q,K,V) = softmax( QKᵀ / √dₖ ) · V
Each token's embedding is multiplied by three learned weight matrices to produce: Q (Query) — what this token is looking for, K (Key) — what each token advertises about itself, V (Value) — the actual content each token contributes.

Step 3 — Raw Attention Scores (dot product)
score(Q, Kᵢ) = Q · Kᵢᵀ / √dₖ
The Query vector is dot-producted with every Key vector. Higher dot product = more relevance. Dividing by √dₖ prevents vanishing gradients in deep dimensions.

Step 4 — Softmax → Attention Weights
αᵢ = exp(scoreᵢ) / Σⱼ exp(scoreⱼ)
Softmax converts raw scores into a probability distribution — all weights sum to 1.0. The temperature slider (above) controls sharpness: low temperature = sharp focus on one token; high temperature = diffuse, spread attention. Drag it now!

Step 5 — Weighted Sum of Values → Output
outputᵢ = Σⱼ αⱼ · Vⱼ
The final output for the query token is a weighted average of all Value vectors, using attention weights αⱼ. Tokens with high attention contribute more to the output. This is how context flows through the model.

Step 6 — Multi-Head Attention
MultiHead(Q,K,V) = Concat(head₁,…,headₙ) · Wᴼ
Instead of one attention function, we run H parallel attention heads, each with its own Q/K/V projections. Each head can learn different relationship patterns (e.g., syntactic, semantic, coreference). Results are concatenated and projected.
